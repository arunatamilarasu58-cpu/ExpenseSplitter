# Expense Splitter

## Project Description

Expense Splitter is a Java console application developed using Object Oriented Programming (OOP) concepts. It helps users manage shared expenses among friends or group members by calculating balances based on the expenses entered.

---

## Features

- Add User
- Show Users
- Add Expense
- Show Balances
- Exit Application

---

## Technologies Used

- Java
- Visual Studio Code
- Object Oriented Programming (OOP)
- ArrayList
- HashMap

## Modules

### Main.java
Controls the menu and overall program execution.

### User.java
Stores user information.

### Expense.java
Stores expense details such as payer and amount.

### ExpenseManager.java
Calculates and manages balances using HashMap.

### Transaction.java
Represents expense transactions.
